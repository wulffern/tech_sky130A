# docs

The Jekyll site for tech_sky130A, published to
<https://wulffern.github.io/tech_sky130A>.

Only the skeleton lives here: `_config.yml` and the `Gemfile`. Every page is
generated by `py/mkdocsite.py` from the markdown next to the files it
documents, so this folder is wiped and rewritten on each build. Write the
prose in `<folder>/<file>.md` and `<folder>/README.md`, never in `docs/`.

The theme is [just-the-docs](https://just-the-docs.com): chapter list in a
sidebar, search across all pages, and prev/next links at the bottom.

## Build it locally

```bash
python3 py/mkdocsite.py
cd docs && bundle install && bundle exec jekyll serve
```

The site is then on <http://localhost:4000/tech_sky130A/>.

## Check for undocumented files

```bash
python3 py/mkdocsite.py --check
```

Exits non-zero when a file has no `.md` beside it, when a folder has no
`README.md`, or when a `.md` documents a file that has been deleted. The DOCS
workflow runs this before it builds, so a new script without documentation
fails CI.
