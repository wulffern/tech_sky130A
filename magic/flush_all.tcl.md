# flush_all.tcl

Reloads every cell in memory from disk, discarding unsaved edits.

Useful when a layout has been regenerated by ciccreator underneath a running
magic session: without this, magic keeps showing the version it loaded at
startup.

```tcl
set values [ cellname list all ]
foreach x $values { flush $x -noprompt }
```

The version check exists because `flush` only learned `-noprompt` after magic
8.3.514; on anything older the script falls back to plain `flush`, which asks
for confirmation per cell.
