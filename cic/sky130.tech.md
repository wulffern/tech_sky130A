# sky130.tech

A symlink to [sky130A.tech](sky130A.tech.md).

```
sky130.tech -> sky130A.tech
```

The name without the variant letter is what ciccreator is invoked with in some
flows, `make ip` for example passes `../cic/sky130.tech`, while the file is
named after the PDK variant it describes. The symlink means both spellings
resolve to the same technology file, so an IP that copies either name into its
own `cic/` directory keeps working.
